# Российское кино для Lampa

Плагин добавляет в верхнюю панель Lampa каталог российских фильмов и сериалов. Он использует TMDB Discover по стране происхождения `RU`, а затем проверяет карточки и показывает только произведения, у которых хотя бы одна производственная компания отмечена в TMDB как российская (`origin_country: RU`). Выбор открывает обычную карточку Lampa, после чего можно запускать ваш привычный поиск торрента.

## Установка

1. В репозитории уже настроен workflow GitHub Actions, который публикует сайт при каждом push в `main`.
2. В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте URL плагина:

   `https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`
3. Откройте настройки раздела **Российское кино** и укажите свой TMDB API Key v3.
4. Перезапустите Lampa. В верхней панели появится значок киноплёнки.

Ключ сохраняется в настройках Lampa на устройстве. Плагин обращается к TMDB напрямую, поэтому ключ будет виден клиенту, на котором установлен плагин. Используйте именно API Key v3, не API Read Access Token; не добавляйте ключ в опубликованный JS-файл или GitHub.

## Публикация через GitHub Pages

Workflow уже опубликовал файл по адресу:

`https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`

Файл плагина статический; отдельный сервер или Telegram-бот не нужны.

## Ограничения данных

Каталог опирается на метаданные TMDB. Страна происхождения и производственные компании должны быть заполнены для карточки, иначе плагин её исключит. Поэтому выдача может быть неполной. TMDB API может ограничивать частоту запросов; плагин кэширует загруженные страницы в памяти на 15 минут.

Для бесплатного некоммерческого использования указывайте TMDB как источник данных и изображений согласно [условиям TMDB](https://www.themoviedb.org/documentation/api/terms-of-use).
