# Российское кино для Lampa

Плагин добавляет каталог российских фильмов и сериалов в меню Lampa и в верхнюю панель. По умолчанию он использует страну производства `RU` по данным TMDB; при желании можно включить строгую проверку российских производственных компаний. Выбор открывает обычную карточку Lampa, после чего можно запускать ваш привычный поиск торрента.

## Установка

1. В репозитории уже настроен workflow GitHub Actions, который публикует сайт при каждом push в `main`.
2. В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте URL плагина:

   `https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`
3. Перезапустите Lampa. В верхней панели появится значок киноплёнки.

Обычно плагин использует встроенный ключ TMDB из Lampa. Если TMDB отвечает `Invalid API key` или `HTTP 401`, откройте **Настройки → Российское кино**, укажите свой **API Key v3** из настроек аккаунта TMDB и перезапустите каталог. Сохранённый ключ используется только на этом устройстве и имеет приоритет над встроенным ключом Lampa. Не вводите API Read Access Token вместо API Key v3.

## Публикация через GitHub Pages

Workflow уже опубликовал файл по адресу:

`https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`

Файл плагина статический; отдельный сервер или Telegram-бот не нужны. Используйте эту постоянную ссылку: при публикации она всегда указывает на последнюю версию плагина. Если Lampa не подтянула обновление сразу, перезапустите приложение или удалите и заново добавьте плагин с тем же адресом.

## Исходники и сборка

Исходный код разделён по назначению в `src/`: TMDB API, фильтры, навигация, карточки каталога, стили и запуск плагина. Перед публикацией GitHub Actions выполняет `npm run check`, который собирает эти модули в один совместимый файл `lampa/russian-cinema.js`, проверяет синтаксис и запуск плагина. Именно этот собранный файл Lampa загружает по постоянной ссылке; отдельные модули на телевизор не запрашиваются.

Для локальной сборки выполните `npm run build`, для сборки и проверок — `npm run check`.

## Каталог

Каталог оформлен как ленты Lampa: крупные скруглённые постеры, рейтинг поверх постера, а название и год — под ним. Фильмы идут первым рядом, сериалы ниже. На пульте вверх/вниз переключают активный ряд, а влево/вправо листают карточки внутри него; вертикальная прокрутка следует за фокусом. Следующие страницы подгружаются автоматически по мере продвижения к концу ленты, без отдельной карточки «Загрузить ещё». Фильтры открываются штатным меню Lampa с подменю и чекбоксами жанров; жанр, год, рейтинг, сортировка и режим производства применяются к обеим лентам. Режим **Шире** использует страну производства `RU` из TMDB; режим **Строго** дополнительно требует российскую производственную студию. При отсутствии русского постера плагин ищет исходный постер из списка TMDB, затем изображения на других языках; если постера нет, использует фон кадра, когда он доступен. Выбор постера открывает штатную полную карточку TMDB в Lampa; дальше используйте установленный у вас поиск торрентов.

## Ограничения данных

Каталог опирается на метаданные TMDB, поэтому выдача может быть неполной или неточной. В строгом режиме карточки без заполненной российской студии исключаются. TMDB API может ограничивать частоту запросов; плагин кэширует загруженные страницы в памяти на 15 минут.

Для бесплатного некоммерческого использования указывайте TMDB как источник данных и изображений согласно [условиям TMDB](https://www.themoviedb.org/documentation/api/terms-of-use).
