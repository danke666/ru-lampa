# Российское кино для Lampa

Плагин добавляет в верхнюю панель Lampa каталог российских фильмов и сериалов. По умолчанию он использует страну производства `RU` по данным TMDB; при желании можно включить строгую проверку российских производственных компаний. Выбор открывает обычную карточку Lampa, после чего можно запускать ваш привычный поиск торрента.

## Установка

1. В репозитории уже настроен workflow GitHub Actions, который публикует сайт при каждом push в `main`.
2. В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте URL плагина:

   `https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`
3. Перезапустите Lampa. В верхней панели появится значок киноплёнки; вручную вводить ключ TMDB не нужно.

Плагин использует встроенный ключ TMDB из Lampa и её штатный сетевой слой.

## Публикация через GitHub Pages

Workflow уже опубликовал файл по адресу:

`https://danke666.github.io/ru-lampa/lampa/russian-cinema.js`

Файл плагина статический; отдельный сервер или Telegram-бот не нужны.

## Каталог

В каталоге можно переключаться между фильмами и сериалами, выбирать жанр, год выпуска и минимальный рейтинг, а также менять сортировку. Режим **Шире** использует страну производства `RU` из TMDB; режим **Строго** дополнительно требует российскую производственную студию. Плагин просматривает до четырёх страниц за один заход, чтобы заполнить каталог, затем предлагает загрузить ещё. Карточки отображаются крупными постерами. Выбор открывает штатную полную карточку TMDB в Lampa; дальше используйте установленный у вас поиск торрентов.

## Ограничения данных

Каталог опирается на метаданные TMDB, поэтому выдача может быть неполной или неточной. В строгом режиме карточки без заполненной российской студии исключаются. TMDB API может ограничивать частоту запросов; плагин кэширует загруженные страницы в памяти на 15 минут.

Для бесплатного некоммерческого использования указывайте TMDB как источник данных и изображений согласно [условиям TMDB](https://www.themoviedb.org/documentation/api/terms-of-use).
